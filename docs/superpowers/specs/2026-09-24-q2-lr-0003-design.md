# 问题 2：A 基线低学习率单变量实验设计

## 目标

在 Attachment 2 的 `train=3395`、`valid=728` 上，以固定 `seed=20260924` 检验一个从 A 独立派生的候选是否能令 clean valid macro-F1 达到 `0.6212527658`。本候选不读取、验证、预测、训练、早停或选模 Attachment 2 `test`。

## 证据与选择

A（`q2-valid-no-train-missingness`）的 clean macro-F1 为 `0.6165677806`，距目标 `0.0046849852`。它及其后续 B、D、F、G 的最佳 checkpoint 都是 epoch 1；只有原始 v4 在 epoch 6 达到最佳。这个跨候选现象与关闭训练期合成缺失后轻量融合头在 `learning_rate=0.001` 下更新过快相符。

已排除的路线不作为该现象的替代解释：不回调 dropout、回归权重、类别权重、极性-强度一致性、MAG-lite、MulT-lite、文本 adapter、late-expert、缺失课程或蒸馏。A 的 text 遮蔽场景显著弱于 audio/vision 遮蔽场景，因而也不通过强行均衡 gate 来压低真实有效的文本证据。

## 唯一变量

候选 H 使用名称 `q2-valid-lr-0003`，从 A 的已记录语义重建：

| 字段 | A | H |
| --- | ---: | ---: |
| `learning_rate` | `0.001` | `0.0003` |
| 所有其他训练字段 | 固定 | 与 A 相同 |

具体地，H 保持对齐版输入、本地冻结 BERT、`gated` 融合、`identity` 文本 adapter、`synthetic_missingness_enabled=false`、30 epochs、batch size 64、AdamW weight decay `0.0001`、hidden size 128、4 heads、2 layers、dropout `0.1`、回归权重 `0.5`、类别权重指数 `1.0`、CUDA 及固定 seed。不得增加 scheduler、warmup、参数组、epoch 数或第二个学习率；不得因结果回调 `0.0003`。

## 运行与边界

真实运行只能使用显式的、此前不存在的输出目录 `artifacts/q2-valid-lr-0003/`。先运行 `train-q2 --check`，要求预检报告精确的 `3395/728/30` 计数；成功后仅运行一次训练。归档、附件数据、原有产物和已保存 checkpoint 均只读。

候选选择只用 clean valid macro-F1。运行产物仍需包含四项 clean 指标、728 条分类报告、27 条缺失场景、30 条附件 3 无标签预测、模型和运行清单。MAE、Pearson、逐类 F1 和场景摘要只作辅助审计，不替代主门槛。

## 判定

接受条件是 clean valid macro-F1 `>= 0.6212527658`。无论结果如何，都写入相对 A 的比较 JSON，证明 normalizer、输入引用和所有固定字段一致，且规范化后的唯一配置差异是 `learning_rate`。若未达到门槛，永久淘汰此精确的低学习率点，不扫其他学习率或加入调度器；后续新方向必须另行预注册。
