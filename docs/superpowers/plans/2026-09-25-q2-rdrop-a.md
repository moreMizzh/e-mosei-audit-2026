# Q2 A-Derived R-Drop Candidate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement and valid-only evaluate exactly one A-derived R-Drop candidate with fixed alpha 1.0, accepting it only at clean valid macro-F1 `>= 0.6212527658`.

**Architecture:** A persisted `dropout_consistency_variant` enum controls training only. `none` preserves the one-view loss; `rdrop_alpha_1` executes two stochastic dropout forwards over the same unique batch/masks, averages the unchanged joint losses, then adds a fixed symmetric classification KL. Inference architecture, model state, BERT, Attachment 3 format, and saved-valid output are unchanged.

**Tech Stack:** Python 3.12, PyTorch, Transformers, pytest, TOML, the existing `e_mosei_audit.q2` runner, and local offline BERT.
