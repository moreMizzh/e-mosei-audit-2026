# Q2 MAG-Lite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one mask-safe, post-BERT MAG-lite fusion variant and run it once on the promoted no-training-missingness control.

**Architecture:** The default `fusion_variant="gated"` remains byte-compatible with the current three-stream gate. `fusion_variant="mag_lite"` computes a bounded nonverbal residual from the already mask-zeroed audio/vision states and their availability bits, then adds it only at text-observed positions before the unchanged three-way gate. This is a local post-BERT adaptation inspired by MAG, not a reproduction of MAG-BERT because this project keeps BERT frozen. Saved-run evaluation defaults missing historical manifest fields to `gated`.

**Tech Stack:** Python 3.12, NumPy, PyTorch, Transformers, pytest, local 7-Zip/BERT assets.

- [ ] **Step 3: Implement the smallest exact variant.**

Add `fusion_variant: str` to Q2 config and require either `"gated"` or `"mag_lite"`. Extend `MaskAwareTemporalFusion` with the same validated argument. For `mag_lite`, instantiate exactly two hidden-width modules using the already projected states:

```python
self.mag_shift = nn.Sequential(nn.Linear(hidden_size * 3 + 2, hidden_size), nn.Tanh())
self.mag_gate = nn.Sequential(nn.Linear(hidden_size * 3 + 2, hidden_size), nn.Sigmoid())
```

After projected states have been mask-zeroed and before the existing three-way `gate_features`, form:

```python
mag_features = torch.cat((*states, availability[..., 1:].to(dtype=text.dtype)), dim=-1)
nonverbal_available = availability[..., 1:].any(dim=-1, keepdim=True)
text_update = states[0] + self.mag_gate(mag_features) * self.mag_shift(mag_features)
text_state = torch.where(
    availability[..., 0:1] & nonverbal_available,
    text_update,
    states[0],
)
states = (text_state, states[1], states[2])
```

`gated` must skip these modules and retain its existing state tuple exactly. This prevents unavailable nonverbal raw values, projection biases, or text-missing positions from leaking into the text stream.

Pass the config variant into `run_q2` model construction and write `training.fusion_variant`. In `evaluate_saved_q2_valid`, reconstruct with a helper that returns `"gated"` if legacy `training.fusion_variant` is absent and otherwise validates one of the two values.
