# Q2 MulT-Lite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one mask-safe, fixed-size MulT-lite fusion variant and evaluate it once from the no-training-missingness A control on Attachment 2 train/valid only.

**Architecture:** `mult_lite` preserves projections, availability-masked three-way gate, temporal Transformer, losses, frozen BERT, checkpoint selection, and missingness scenarios. Between mask-zeroed projections and the unchanged gate, it creates two parallel one-layer cross-attention contexts (`text <- audio`, `text <- vision`), averages available contexts, and normalizes the residual with text. A sample without text queries or K/V positions does not call `nn.MultiheadAttention`; its context is zero. This is a narrow directional-interaction test inspired by MulT, not a reproduction of its full stack.

**Tech Stack:** Python 3.12, PyTorch `nn.MultiheadAttention`, NumPy, Transformers, pytest, local 7-Zip/BERT assets.

Add this private helper. It filters out all-masked samples before PyTorch attention, masks unavailable query positions after attention, and uses functional `index_copy` to preserve gradients:

```python
def _cross_attention_context(self, *, query, source, query_available, source_available, attention):
    active = query_available.any(dim=1) & source_available.any(dim=1)
    context = torch.zeros_like(query)
    indexes = active.nonzero(as_tuple=False).squeeze(1)
    if indexes.numel() == 0:
        return context
    attended, _ = attention(
        query[indexes], source[indexes], source[indexes],
        key_padding_mask=~source_available[indexes], need_weights=False,
    )
    attended = attended.masked_fill(~query_available[indexes].unsqueeze(-1), 0.0)
    return context.index_copy(0, indexes, attended)
```

After existing projections have been mask-zeroed and before unchanged `gate_features`, apply the helper twice. The state update must be exactly:

```python
audio_context = self._cross_attention_context(query=states[0], source=states[1], query_available=availability[..., 0], source_available=availability[..., 1], attention=self.text_from_audio)
vision_context = self._cross_attention_context(query=states[0], source=states[2], query_available=availability[..., 0], source_available=availability[..., 2], attention=self.text_from_vision)
nonverbal_present = availability[..., 1:].any(dim=1)
source_count = nonverbal_present.sum(dim=-1).clamp_min(1).to(dtype=text.dtype).view(-1, 1, 1)
text_update = self.mult_lite_norm(states[0] + (audio_context + vision_context) / source_count)
can_update_text = availability[..., 0:1] & nonverbal_present.any(dim=-1).view(-1, 1, 1)
states = (torch.where(can_update_text, text_update, states[0]), states[1], states[2])
```
